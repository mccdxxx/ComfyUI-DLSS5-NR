# v0.2.0

First GitHub-release-oriented build of the unofficial DLSS 5 Neural Rendering ComfyUI node.

Highlights:

- in-process D3D12/NGX Neural Rendering, no helper executable;
- prebuilt project-owned Windows bridge/helper generated by GitHub Actions;
- normal users no longer need Visual Studio Build Tools;
- automatic `_nvngx.dll` discovery from NVIDIA DriverStore;
- still-image and temporal-sequence modes;
- automatic/manual RGBA/BGRA output handling;
- runtime diagnostics with GPU name and `nvngx_dlssnr.dll` SHA-256;
- CI guard against accidentally distributing NVIDIA proprietary runtime DLLs.

Users must provide their own compatible, legally obtained `runtime/nvngx_dlssnr.dll`.

This is an unofficial experimental integration with an undocumented/pre-release interface. It is not supported or endorsed by NVIDIA or Comfy Org.
